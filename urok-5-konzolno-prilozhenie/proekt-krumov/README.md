# Списък със задачи

Програмата пази списък със задачи в текстов файл: добавя нови, показва ги, отбелязва ги като изпълнени и ги изтрива, а списъкът се запазва между стартиранията.

Стартира се от тази папка с `python main.py` (няма външни пакети; проверките се пускат с `python -m pytest -v` от средата в корена на хранилището).
