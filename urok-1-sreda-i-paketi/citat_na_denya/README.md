# Цитат на деня

Програмата чете цитатите от `data/citati.txt` и показва в рамка един цитат, който е един и същ през целия ден и се сменя на следващия.

Стартира се така: в тази папка създайте среда (`python -m venv .venv`), активирайте я (`.venv\Scripts\activate`), инсталирайте зависимостите (`python -m pip install -r requirements.txt`) и изпълнете `python citat.py`.
